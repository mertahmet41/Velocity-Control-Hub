# 🏎️ Velocity Control Hub (v3.0.0)

Universal Force Feedback & DIY Sim Racing Hardware Platform.
Compatible with OpenFFBoard, STM32F411CEU6 (WeAct Black Pill), BTS7960, Optical Encoders, Pedals & Shifters.

## 🌟 Key Features
- **All-in-One Controller**: Steering wheel, 3-Axis 10k Pedals and 6+R H-Shifter on a single microcontroller.
- **Hardware Spoofing**: Switch identity to OpenFFBoard Native, Logitech G29 or Moza Racing on the fly.
- **Auto-Calibration (Homing)**: Physical hard stop detection (900 degrees) with automatic centering.
- **Case RGB Breathing LED**: Hardware TIM2 PWM breathing animation on PA0, PA1, PA2.
- **Windows Integration**: Standalone installer with Control Panel (Add/Remove Programs) registration.

## 🛠️ Firmware
Includes pre-compiled Firmware/OpenFFBoard_F411CE_V3_Profiles.hex for STM32F411CEU6.
